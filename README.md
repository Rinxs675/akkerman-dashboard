# AKKERMANN Дашборд Производства

## 1. Описание проекта
**AKKERMANN Дашборд** — это система корпоративного телевидения и информирования сотрудников (Digital Signage). 
Проект предназначен для вывода производственных графиков, показателей эффективности, актуальных новостей и уведомлений о происшествиях (инцидентах) на большие экраны в цехах и телевизоры. 

Система работает в **реальном времени**: когда администратор загружает новый Excel-отчет или добавляет новость, данные моментально синхронизируются на всех подключенных устройствах без необходимости перезагрузки страницы (благодаря технологии WebSocket).

---

## 2. Структура кода

### 🖥️ Фронтенд (`/src/`)
Клиентская часть написана на React + Vite. Отвечает за визуализацию данных.

* **`main.jsx`** — Главная точка входа в React приложение.
* **`App.jsx`** — Настройка маршрутизации приложения (React Router). Содержит правила переходов между страницами `/`, `/slides`, `/login` и `/admin`.

#### Папка `src/pages/` (Страницы)
* **`Landing.jsx`** — Стартовая страница-меню, где пользователь выбирает роль: "Просмотр слайдов" (для ТВ) или "Панель администратора".
* **`Dashboard.jsx`** — Основной движок дашборда. В зависимости от переданного параметра `isAdmin`, включает или отключает возможность редактирования. Управляет автоматической сменой слайдов и синхронизацией по сети.
* **`AdminLogin.jsx`** — Форма авторизации для панели администратора.

#### Папка `src/components/` (Компоненты интерфейса)
* **`HeaderNav.jsx`** — Верхняя навигационная панель. Показывает статус подключения к серверу и активный Excel-файл. В режиме админа отображает кнопки управления базой и контентом.
* **`Slideshow.jsx`** — Контейнер, отвечающий за красивый анимированный переход между различными графиками и текстами.
* **`HorizontalBarChart.jsx`** / **`BarChart.jsx`** / **`TextSlide.jsx`** — Компоненты для отрисовки конкретных типов графиков (например, плана/факта добычи и отклонений).
* **`ManagementModals.jsx`** — Модальные (всплывающие) окна для администратора (история Excel-файлов, добавление/удаление новостей и инцидентов).

#### Папка `src/utils/` (Утилиты)
* **`excelParser.js`** — Читает загруженный файл `.xlsx` и превращает его в понятные для графиков структуры данных JSON.
* **`syncManager.js`** — Управляет связью с сервером через сокеты (Socket.io). Отвечает за прием команд на синхронизацию (например, "переключить слайд" или "пришел новый файл").

---

### ⚙️ Бэкенд (`server.js`)
Серверная часть написана на Node.js + Express. Отвечает за хранение файлов, базу данных SQLite (история загрузок) и раздачу данных клиентам по API и сокетам.

**Основные маршруты (Endpoints) в `server.js`:**
* `POST /api/login` — Проверяет пароль и выдает JWT-токен для доступа к закрытым функциям.
* `GET /api/status` — Возвращает статус сервера (сколько экранов подключено).
* `GET /api/latest-excel` — Скачивает самый свежий активный Excel файл для отображения на графиках.
* `POST /api/upload` (🔐 Защищен) — Загрузка нового файла Excel администратором.
* `GET /api/excel-history` — Выдает список всех загруженных ранее Excel файлов.
* `POST /api/excel-select/:id` (🔐 Защищен) — Назначает старый файл из базы как "активный" (восстановление).
* `DELETE /api/excel-file/:id` (🔐 Защищен) — Удаляет Excel файл из системы.
* `GET /api/incidents` — Загружает список активных происшествий (микротравмы, ДТП).
* `POST /api/incidents` (🔐 Защищен) — Добавление новой карточки инцидента (фото + описание).
* `DELETE /api/incidents/:id` (🔐 Защищен) — Удаление инцидента.
* `GET /api/news` — Загружает список новостей, у которых не истек срок показа.
* `POST /api/news` (🔐 Защищен) — Загрузка новости (с таймером старта и окончания показа).
* `DELETE /api/news/:id` (🔐 Защищен) — Принудительное удаление новости.

> Все маршруты с пометкой 🔐 Защищен требуют передачи JWT-токена в заголовке `Authorization: Bearer <token>`. Без входа в админку эти маршруты выдадут `401 Unauthorized`.

## 3. Где и как меняется пароль администратора

Пароль от админ-панели хранится и проверяется исключительно на бэкенде в файле **`server.js`** на 17-й строчке:

```javascript
const ADMIN_PASSWORD = process.env.ADMIN_PASSWORD || 'akkermann2026';
```

**Есть 2 способа его поменять:**

### Способ 1: Изменить прямо в коде (Быстрый)
Открой `server.js`, найди строку №17 и замени `'akkermann2026'` на свой пароль:
```javascript
const ADMIN_PASSWORD = process.env.ADMIN_PASSWORD || 'MoyNoviyParol';
```
После этого сохрани файл и сделай `git commit` + `git push`. Как только сервер (Render) перезагрузится, пароль изменится.

### Способ 2: Изменить через переменные окружения на Render (Безопасный и Правильный)
Чтобы пароль не "светился" в исходном коде на GitHub:
1. Зайди в настройки своего приложения на сайте **Render.com**.
2. Перейди в раздел **Environment** (Переменные окружения).
3. Нажми **Add Environment Variable**.
4. В поле `Key` напиши: `ADMIN_PASSWORD`
5. В поле `Value` напиши свой настоящий сложный пароль (например, `Akk2026_Secure!`).
6. Сохрани настройки (Save Changes). Render автоматически перезапустит сервер с новым паролем.

При таком подходе пароль в коде (`'akkermann2026'`) будет просто игнорироваться, так как система будет использовать секретное значение из настроек Render (`process.env.ADMIN_PASSWORD`).
